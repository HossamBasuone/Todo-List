TaskFlow is a modern, responsive Todo List web application built with HTML, CSS, and JavaScript. It helps users organize daily tasks, track their progress, and stay productive through a clean and user-friendly interface.

Personal Note: I developed this project during my military service, using my free time to continue learning, practice frontend development, and improve my programming skills. This project reflects my commitment to continuous learning and personal growth, even with a busy schedule.

TaskFlow — Organize your day, one task at a time.

✨ Features
➕ Add Tasks: Create new tasks quickly and easily.
✅ Complete Tasks: Mark tasks as completed or uncompleted.
🗑️ Delete Tasks: Remove individual tasks.
📊 Task Statistics: View total, completed, and remaining tasks.
🔍 Search Tasks: Find tasks using the search bar.
🎯 Filter Tasks: Display all, completed, or uncompleted tasks.
#️⃣ Hashtag Categories: Organize tasks using tags such as #work, #health, #study, and #fitness.
🏷️ Tag Filtering: Click a hashtag to filter tasks by category.
📈 Progress Tracking: Monitor task completion with a dynamic progress bar.
💾 Local Storage: Keep tasks saved in your browser after refreshing the page.
📱 Responsive Design: Works on desktop, tablet, and mobile screens.
♿ Accessibility: Includes accessible labels and keyboard focus indicators.
🛠️ Technologies Used
HTML5 — Structures the application.
CSS3 — Provides styling, responsive layouts, and transitions.
JavaScript (ES6+) — Handles task management, searching, filtering, and dynamic updates.
Local Storage API — Saves tasks in the browser.

🚀 Getting Started
Prerequisites

You only need a modern web browser and a code editor such as Visual Studio Code.

1. Clone the repository
git clone YOUR_REPOSITORY_URL


Replace YOUR_REPOSITORY_URL with your actual GitHub repository URL.

2. Open the project folder
cd YOUR_PROJECT_FOLDER

3. Run the application

Open index.html in your browser.

Alternatively, use the Live Server extension in Visual Studio Code.

No additional packages or installation steps are required.

💡 How to Use
Enter a task in the input field.
Add hashtags to categorize your task, such as Read a book #learning.
Click Add task to add it to your list.
Check the checkbox when you finish a task.
Use the search bar to find specific tasks.
Select a status from the filter menu to view relevant tasks.
Click a hashtag to filter tasks by category.
Track your progress using the statistics and progress bar.
Delete individual tasks or remove all completed tasks.
💾 Data Storage

TaskFlow uses the browser's Local Storage API to save tasks on your device.

Your tasks remain available after refreshing the page in the same browser. However, they are not automatically synchronized across different browsers or devices.
